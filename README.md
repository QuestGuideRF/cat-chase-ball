# 🐱 Кот Ловит Мяч

Увлекательная мини-игра на Python, где озорной котик пытается поймать непослушный мячик!

Простая, но затягивающая игра с плавной анимацией и интуитивным управлением.
Идеально подходит для изучения основ разработки игр на Python или просто для отдыха.

---

## 🎮 Управление

**Всё очень просто:**

- 🖱️ **Двигайте мышью** внутри окна — котик будет преследовать курсор
- 🎯 **Левая кнопка мыши** — телепортирует цель в случайное место на экране
- ⌨️ **Esc** или закрытие окна — выход из игры

---

## 🚀 Установка и Запуск

### 📋 Требования

- **Python 3.8** или выше
- Работает на **Windows** (и других платформах с поддержкой Pygame)
- Требуется установка библиотеки Pygame

### 🔧 Установка зависимостей

```bash
pip install pygame
```

### ▶️ Запуск игры

```bash
python cat_chase_ball.py
```
